Tool sederhana untuk download video dan audio dari TikTok.

Project ini dibuat untuk kebutuhan pribadi dan belajar. Dengan aplikasi ini, kamu bisa menyalin link TikTok lalu mengunduh konten yang diinginkan dengan proses yang mudah.

## ✨ Fitur
- Download video TikTok
- Download audio dari video
- Pilih format dan kualitas
- Proses yang mudah dipakai
- Antarmuka sederhana dan cepat

## 🚀 Cara Pakai

1. Clone repository
2. Install dependencies
3. Jalankan aplikasi
4. Masukkan link TikTok
5. Pilih format download

```bash
git clone https://github.com/LiliyanaDeZenith/Tiktok.downloader.git
cd Tiktok.downloader
npm install
npm start
